# AutoAntigravity

Расширение для Antigravity, которое объединяет функции **Auto Accept (Автопринятие)** и **Ralph Loop (Цикл Рэйфа)** в одном плагине.

---

## ✨ Основные возможности

### ⚡ Auto Accept (Автопринятие)
Автоматически принимает **изменения файлов, команды терминала и запросы разрешений**, предлагаемые агентом Antigravity.

- **CDP (Chrome DevTools Protocol) + MutationObserver**: Мгновенно обнаруживает изменения DOM → Автоматически нажимает кнопки
- **Опрос VS Code Commands API**: Автоматически выполняет `acceptAgentStep`, `terminalCommand.run` и т.д.
- **Обнаруживаемые кнопки**: `Run`, `Accept`, `Always Allow`, `Allow`, `Retry`, `Continue`
- **Поддержка добавления пользовательского текста кнопок** (мультиязычная поддержка)

### 🔄 Ralph Loop (Цикл Рэйфа)
Система **циклического автономного выполнения агентов** на основе файла `PRD.md`.

- **На основе файлов задач**: Управляет задачами в формате чекбоксов (`- [ ]`) в файле `PRD.md`
- **Поддержка параллельных задач**: Независимое параллельное выполнение задач с использованием git worktrees (рабочих деревьев) с помощью тега `#parallel` и их автоматическое слияние
- **Отслеживание прогресса**: Записывает результат каждой итерации с использованием метода добавления (append-only) в файл `progress.txt`
- **Автоматический коммит (Auto Commit)**: В Git после каждой итерации
- **Обновление контекста**: Преодолевает ограничения окна контекста путем запуска нового сеанса для каждой итерации
- **Меры безопасности**: Ограничивает максимальное количество итераций во избежание бесконечных циклов

### 📱 Интеграция с Telegram-ботом
Мониторинг и управление рабочими процессами с помощью Telegram-бота.

- **Простая настройка пользовательского интерфейса**: Зарегистрируйте токен бота и Chat ID прямо в панели настроек боковой панели AutoAntigravity
- **Безопасное хранение**: Безопасное сохранение и управление настройками бота с использованием файла `.env`
- **Уведомления и многое другое**: Закладывает основу для ключевых расширений, таких как мониторинг задач агента

## 🛠 Установка

### 1. Включите режим отладки (Обязательно)
Добавьте следующий флаг при запуске Antigravity:

```
--remote-debugging-port=9559
```

**Windows**: Добавьте флаг в поле Объект в Свойствах ярлыка  
**Mac**: `open -a "Antigravity" --args --remote-debugging-port=9559`  
**Linux**: Добавьте флаг в строку Exec вашего файла `.desktop`

> 💡 После установки, если порт закрыт при первом запуске, будет отображено уведомление об автоматическом исправлении.

### 2. Установка расширения
Найдите `AutoAntigravity` в **Панели расширений (Extensions Panel)** приложения Antigravity, чтобы установить его.
- [Страница AutoAntigravity в Open VSX Registry](https://open-vsx.org/extension/shinepcsg/AutoAntigravity)

## 📖 Использование

### Auto Accept
- **Переключатель**: Нажмите `⚡ AutoAccept: ON` / `✕ AutoAccept: OFF` в строке состояния
- **Команда**: `Ctrl+Shift+P` → `AutoAntigravity: Toggle Auto Accept`

### 📱 Настройка Telegram-бота
Вы можете привязать Telegram-бота для мониторинга задач и получения уведомлений.

1. **Создайте бота**: Создайте бота в Telegram через `@BotFather` и получите **Bot Token**.
2. **Узнайте Chat ID**: Отправьте сообщение боту или используйте такие инструменты, как `@msid_bot`, чтобы узнать свой **Chat ID**.
3. **Регистрация настроек**: Откройте панель боковой панели, нажав на **значок AutoAntigravity** на левой панели активности.
4. Введите ваш Токен (Token) и Chat ID в меню **Telegram Integration Management** панели и сохраните.
   > 💡 *Настроенная информация безопасно сохраняется в файле `.env` в корне рабочей области.*

### 🔄 Ralph Loop
1. **Подготовьте файл задач**: Создайте файл `PRD.md` в вашей рабочей области (в формате чекбоксов)
   ```markdown
   - [ ] Реализовать конечную точку API
   - [ ] Спроектировать схему базы данных
   - [ ] Написать модульные тесты
   ```
2. **Запуск**: `Ctrl+Shift+P` → `AutoAntigravity: Start Ralph Loop`
3. **Остановка**: `Ctrl+Shift+P` → `AutoAntigravity: Stop Ralph Loop`

### Регистрация рабочего процесса `/write-prd`

С помощью команды с косой чертой `/write-prd` агент искусственного интеллекта автоматически составляет PRD и мгновенно применяет его к Ralph Loop.  
Чтобы использовать этот рабочий процесс, вам необходимо зарегистрировать его как **Глобальный рабочий процесс** или **Рабочий процесс проекта**.

#### Метод 1: Рабочий процесс проекта (Использование только в текущем проекте)

Поместите файл `.agent/workflows/write-prd.md` в корень вашего проекта.  
Поскольку он уже включен в репозиторий AutoAntigravity, просто скопируйте файл для использования в других проектах.

```
your-project/
├── .agent/
│   └── workflows/
│       └── write-prd.md    ← Поместите файл сюда
├── PRD.md
└── ...
```

> 💡 Также поддерживаются пути `.agents/workflows/`, `_agent/workflows/` и `_agents/workflows/`.

#### Метод 2: Глобальный рабочий процесс (Использование во всех проектах)

Разместив файл в папке `.agent/workflows/` вашего домашнего каталога, вы сможете использовать команду `/write-prd` во всех проектах.

**Windows** (Выполнить в корне проекта):
```powershell
# Создать каталог глобального рабочего процесса
New-Item -ItemType Directory -Path "$env:USERPROFILE\.agent\workflows" -Force

# Скопировать write-prd.md
Copy-Item ".\.agent\workflows\write-prd.md" "$env:USERPROFILE\.agent\workflows\write-prd.md"
```

**Mac / Linux** (Выполнить в корне проекта):
```bash
# Создать каталог глобального рабочего процесса
mkdir -p ~/.agent/workflows

# Скопировать write-prd.md
cp ./.agent/workflows/write-prd.md ~/.agent/workflows/write-prd.md
```

После регистрации введите `/write-prd` в чате Antigravity, чтобы запустить процесс.

### 🔀 Настройка параллельных задач

Ralph Loop может одновременно выполнять задачи, отмеченные тегом `#parallel`, в **независимых рабочих деревьях (git worktrees)**.

#### Активация

Параллельное выполнение включено по умолчанию. Этим можно управлять в настройках:

| Настройка | По умолчанию | Описание |
|---|---|---|
| `autoAntigravity.ralphLoop.enableParallel` | `true` | Включить/выключить параллельное выполнение |
| `autoAntigravity.ralphLoop.maxParallelTasks` | `3` | Максимальное количество параллельных задач (2~8) |

#### Указание параллельных задач в PRD

Добавьте тег `#parallel` в элементы задач, чтобы выполнить их параллельно:

```markdown
### Шаг 2: Внедрение независимых модулей
- [ ] #parallel Задача 2-1: Внедрение модуля пользователя (src/user.js)
- [ ] #parallel Задача 2-2: Внедрение модуля продукта (src/product.js)
- [ ] #parallel Задача 2-3: Внедрение модуля заказа (src/order.js)
- [ ] Проверка 2: Убедитесь, что все модули проходят модульные тесты
```

#### Правила параллельных задач

- **Последовательно идущие элементы с `#parallel`** формируют единую группу параллельных задач.
- Если обычная задача (без тега) находится между ними, они разделяются на **разные параллельные группы**.
- Используйте параллельные задачи **только для изменения разных файлов** — изменение одного и того же файла вызовет конфликт слияния.
- **Не используйте** параллельность для задач, которые зависят от результатов предыдущих задач в той же группе.

#### Как это работает

1. Когда система обнаруживает параллельную группу, создается **независимый git worktree** для каждой задачи.
2. Отдельный агент Antigravity выполняет задачу параллельно в каждом рабочем дереве.
3. Как только все задачи выполнены, их результаты **автоматически объединяются в основную ветку (main branch)**.
4. Если возникает конфликт слияния (merge conflict), ИИ попытается устранить его автоматически.

## ⚙ Настройки

| Настройка | Значение | Описание |
|---|---|---|
| `autoAntigravity.autoAccept.pollInterval` | `500` | Интервал опроса (мс) |
| `autoAntigravity.autoAccept.cdpPort` | `9559` | Порт отладки CDP |
| `autoAntigravity.autoAccept.customButtonTexts` | `[]` | Дополнительный текст кнопок |
| `autoAntigravity.ralphLoop.maxIterations` | `50` | Максимальное количество итераций |
| `autoAntigravity.ralphLoop.taskFile` | `PRD.md` | Имя файла задач |
| `autoAntigravity.ralphLoop.progressFile` | `progress.txt` | Имя файла прогресса выполнения |
| `autoAntigravity.ralphLoop.autoCommit` | `true` | Автоматически применять git commit |
| `autoAntigravity.ralphLoop.autoDeleteBranch` | `true` | Автоматически удалять рабочую ветку после выполнения |
| `autoAntigravity.ralphLoop.iterationDelayMs` | `1500` | Задержка цикла (мс) |
| `autoAntigravity.ralphLoop.allowPrdModification` | `false` | Разрешать агентам вносить изменения в PRD |
| `autoAntigravity.ralphLoop.autoStart` | `true` | Автозапуск при изменении файла задач |
| `autoAntigravity.ralphLoop.enableParallel` | `true` | Параллельное выполнение активировано |
| `autoAntigravity.ralphLoop.maxParallelTasks` | `3` | Максимальное количество параллельных задач (2~8) |

## 🔒 Безопасность

- Auto Accept работает **только внутри панели агента Antigravity** (Webview Guard)
- Он не взаимодействует с внешними веб-страницами и вкладками браузера
- CDP настроен **исключительно для localhost** — внешний доступ к сети отсутствует
- Ralph Loop ограничивает максимальное количество итераций для предотвращения бесконечных циклов
